# Procesador de datos de ventas

Ejecuta `python main.py` desde esta carpeta. El reporte se guarda en `data/reports/reporte_final.txt`.

## Segunda entrega y PostgreSQL

La rama Sergio incluye el esquema relacional, conexión Psycopg 3, persistencia
transaccional y pruebas de integración. Consulta
[la guía de PostgreSQL](docs/postgresql_sergio.md) para configurar el servidor,
crear la base y ejecutar `postgres.py conexion`, `inicializar`, `demo` y `listar`.

El flujo de `main.py` todavía usa CSV; la integración del extractor, consultas
de métricas y reporte se realizará con las partes de Gabriela, Ricardo y Melissa.
